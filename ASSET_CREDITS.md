### Important note about the Iyume avatars

The game currently changes the avatar's runtime scale, material/rendering properties, and humanoid bone poses for movement and sitting. These changes are not written back to the `.vrm` files, but are still changes to the model's runtime presentation. Because the embedded terms disallow modification, get permission from the creator or replace these avatars before distributing a build that applies these changes. Commercializing the game (including monetization such as paid content or potentially donations) also needs permission; the exact treatment of donations is not specified in the embedded metadata.
